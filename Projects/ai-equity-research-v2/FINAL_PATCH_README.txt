1. Tutup Streamlit jika sedang berjalan.
2. Ekstrak seluruh isi ZIP ini langsung ke folder:

4. File proyek lain, .env, database SQLite, dan Task Scheduler tidak disentuh.
5. Setelah seluruh perubahan diterapkan, jalankan FINAL_TESTS.bat satu kali.

Jangan mengunggah .env atau database lokal ke GitHub.
